# 읽걷쓰AI 수업을 위한 H-A-H 프롬프트 라이브러리

초등 수업을 위한 공개·로그인 없는 프롬프트 자료실. 원고 기반 3사례와 Chan(2026) v2의 9가지 인지적 지원 기능을 연결합니다. 기능·수업 연결·프롬프트는 교육적 재구성이며 초등 학습효과를 검증했다는 뜻이 아닙니다.

## 실행
Node.js 20 이상. 외부 npm 패키지가 필요하지 않습니다.

- `npm run dev`: 로컬 서버 (4173)
- `npm run check`: 문법 검사와 단위 테스트
- `npm run build`: 정적 배포 파일을 dist에 생성

Vercel: Framework Preset Other, Build Command `npm run build`, Output Directory `dist`.

## 개인정보
백엔드·AI API·분석 추적·로그인·저장 기능 없음. 입력값은 브라우저 메모리에서 프롬프트에 반영됩니다. 사용자가 복사한 후 선택한 외부 챗봇에 제공하는 내용은 그 서비스의 정책에 따릅니다. 웹폰트 로딩 시 Google Fonts로 일반 네트워크 요청이 발생합니다.

## 콘텐츠
`content.json`: 사례와 기능, 프롬프트. `index.html`: 이론과 공개 출처. 비공개 원고, 원본 학생 산출물, 계정 정보는 저장소에 포함하지 않습니다. 실제 교실 활용 전 학교 지침·서비스 연령 요건·프롬프트 동작을 교사가 확인해야 합니다.
